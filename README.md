# Smart Face Detection System 👁️

A real-time face, eye, and smile detection system using OpenCV Haar Cascades.

## 🚀 Features
- Real-time face detection
- Eye detection inside face ROI
- Smile detection
- Live webcam processing

## 🧠 Tech Stack
- Python
- OpenCV

## 📷 How it works
1. Captures webcam feed
2. Converts frame to grayscale
3. Detects faces using Haar cascade
4. Detects eyes and smile in face region
5. Draws bounding boxes and labels
